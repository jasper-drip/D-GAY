placeholder guide

Use this before you drop in a Word template. The checker only replaces tags it can read, then writes GAY100% in red.

  1. 1 UploadDrop a .docx file, or click the box. Word templates only, up to 16 MB.
  2. 2 CheckRun D-GAY Checker. The variables list shows every placeholder that was found.
  3. 3 YieldRead the preview, then download the document with each placeholder replaced.

How a placeholder has to look

  • Write it as {{ name }}. {{name}} is the same tag. Spaces around the name are fine.
  • Start the name with a letter or _. After that, use letters, digits, or _.
  • {{ user.email }} reads a value inside an object. {{ amount|upper }} adds a filter.
  • {{ item.label }} works inside {% for item in items %}. The loop itself is not a placeholder.
  • A tag split across Word formatting is still found. The checker joins the text of the paragraph first.

Hyphens

  • {{site-24h}} and {{foo-bar}} are recognized. The hyphen must sit directly between letters, digits, or underscores.
  • The variables list keeps the hyphen. While checking, foo-bar is read as foo_bar so the template can render. The download still shows GAY100%.
  • {{ foo - bar }} is not a name. The spaces make the hyphen a minus sign.
  • {{-}} and {{ - }} are not placeholders. A hyphen by itself has no name.
  • {{ 24hours }} and {{ my name }} are skipped. A name cannot start with a digit or contain a space.
  • A hyphen inside {% for item in foo-bar %} is not rewritten. Hyphens are only accepted inside {{ }} tags.
